# Lift — инструкция для Claude

PWA-дневник тренировок владелицы. Пользуется с iPhone 15 Pro как приложением с экрана «Домой».
Сайт: https://fdrlit.github.io/lift/ (GitHub Pages, ветка `main`, корень репозитория).

## Как выкладывать правки

Владелица хочет: написала правку → она сразу на сайте, без её участия.
После каждой проверенной правки: `git add -A && git commit && git push origin main`.
Pages пересобирается сам (~1 мин). Service worker берёт код из сети первым, так что
обновление приходит при следующем открытии приложения. Номер `CACHE` в `sw.js` менять
только при изменении состава SHELL.

## Общение

- Только по-русски, никогда по-украински.
- Владелица — девушка: обращаться в женском роде.
- Коротко и по делу.

## Правила продукта

- Дизайн минималистичный: шрифты Onest (текст) + Archivo (цифры), токены в `:root` и
  `[data-theme=…]` в `index.html`. Без градиентов, свечений, эмодзи, конфетти — это было
  отвергнуто как «ИИ-слоп».
- Темы: светлая/тёмная/авто + 7 розовых (по умолчанию «Пудра»). Новую тему — блок
  `:root[data-theme=…]` в CSS и строка в `THEMES` в app.js.
- Медиа упражнений: **генеративные картинки запрещены**. Только реальные видео со свободной
  лицензией (Pexels, Mixkit), приоритет — девушки, мужчины допустимы. Цветные, не ч/б.
  Видео → `vid/<id>.mp4` + `vid/<id>.jpg` (640px, без звука, crf 30, ~6 с цикл),
  фото → `img/<id>_0.jpg`, `_1.jpg` (free-exercise-db). Прежде чем добавить видео —
  проверить технику по кадрам.
- «Мои упражнения» (`MY_LEGS`, `MY_UPPER` в app.js) — основной список владелицы, показывается
  первым. Названия — её формулировки.
- Данные только в localStorage телефона; формат `lift.v1` не ломать (есть экспорт/импорт).
